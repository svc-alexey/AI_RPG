# AI RPG «Стирая Грань» — Итоговый дизайн-отчёт

**Дата:** 2026-05-05
**Покрытие:** 70+ скриншотов, 10 экранов Flutter, 6 статических страниц
**Инструменты:** MCP Marionette (Flutter), gstack browse/Playwright (статика), CDP (Chrome)

---

## Общая оценка: 7.2/10

Сильный фундамент — тёмная Noir-эстетика, медный акцент, литературная типографика. Проблемы集中在 accessibility, консистентности состояний и мелких визуальных багах.

## 4. NEW GAME WIZARD (6 шагов)

| Параметр | Оценка | Комментарий |
|----------|--------|-------------|
| Прогресс-бар | 9/10 | «Шаг N из 6» — чёткая индикация |
| Контент шагов | 8/10 | Жанры → Сеттинг → Режим+Сложность → Персонаж → Завязка → Обзор |
| Локализация | 5/10 | Смесь русского и английского в жанрах/сеттингах |

### Находки по шагам

**Шаг 1 (Жанр):**
- 10 жанровых чипов: Романтика, Romantasy, Фэнтези, Триллер, Детектив, Хоррор, Young Adult, Sci-Fi, Dark academia, Cozy
- **⚠️ Смесь языков**: «Romantasy», «Young Adult», «Sci-Fi», «Dark academia», «Cozy» — на английском при русской локали
- **✅ Описание жанра** при выборе — помогает принять решение
- **⚠️ Кнопка «Случайный жанр»** — хорошая идея для неопределившихся

**Шаг 2 (Сеттинг):**
- 10 вариантов: Романтическое фэнтези, Уютное фэнтези, Тёмная академия, Постапокалипсис, LitRPG, Гримдарк, НФ близкого будущего, Хоррор, Cozy crime, Альт-история
- **⚠️ Та же проблема**: «LitRPG», «Cozy crime» на английском
- **✅ Динамическая подборка** — сеттинги зависят от выбранного жанра

**Шаг 3 (Режим + Сложность):**
- Режим: «Короткая история» (единственный видимый вариант)
- Сложность: «Легко» (единственный видимый вариант)
- **⚠️ Минимальный UI** — возможно, есть другие варианты не видные сразу

**Шаг 4 (Персонаж):**
- Раса: «Человек», Пол: «Другой»
- **✅ Опционально** — «настройте персонажа или оставьте по умолчанию»
- **✅ «Случайный персонаж»** — быстрое заполнение

**Шаг 5 (Завязка):**
- Поле ввода стори-промпта
- **⚠️ «Автоматическая генерация портрета временно отключена»** — непонятно когда вернётся

**Шаг 6 (Обзор):**
- Сводка всех выборов: жанр, сеттинг, режим, сложность, персонаж, активные системы
- **✅ Чисто, сканируемо** — иконки + подписи + значения
- **✅ CTA**: «Всё готово! Нажмите 'Создать кампанию' для начала.»
- **⚠️ «Имя героя» показывает плейсхолдеры**: «Мира, Ясень, Грач...» — но поле пустое

### Общие проблемы wizard
- **⚠️ Дублирование кнопки «Назад»** — в шагах 2-6 AppBar.back + инлайн-кнопка Назад
- **⚠️ Разное положение кнопки «Назад»** — то в AppBar, то инлайн

## 9. ДИЗАЙН-СИСТЕМА (Aether)

| Компонент | Оценка | Комментарий |
|-----------|--------|-------------|
| Цвета | 9/10 | Медь + тёплые серые — отлично |
| Типографика | 7/10 | Playfair+Inter хороши, но не унифицированы |
| Компоненты | 8/10 | AetherCard, AetherPageReveal, AetherBackdrop |
| Доступность | 3/10 | Нет фокус-индикаторов, контраст textDim FAIL |

### Проблемы цветового контраста
| Токен | Цвет | Контраст | Статус |
|-------|------|----------|--------|
| textPrimary / bg | #E8E4E0 / #0A0908 | ~15:1 | ✅ AAA |
| textMuted / bg | #7A7570 / #0A0908 | ~5.5:1 | ✅ AA |
| **textDim / bg** | **#5A5550 / #0A0908** | **~3.8:1** | **❌ FAIL** |
| accent / bg | #C87941 / #0A0908 | ~4.6:1 | ⚠️ Только large text |

### Проблемы accessibility
1. **Нет фокус-индикаторов** — тема глобально отключает splash/highlight (WCAG 2.4.7)
2. **Нет Tab-order** — формы не навигируются с клавиатуры
3. **Enter не отправляет формы** — нужно жать кнопку мышью
4. **Legal-ссылки 10px** — область касания ~28px (минимум 44px)
5. **textDim** (#5A5550) — не проходит WCAG AA для body-текста
