Политика конфиденциальности

Сервис обрабатывает email, отображаемое имя, промпты, сюжетный контент, технические логи, статистику использования и данные, необходимые для платежей.

1. Цели обработки

Данные используются для авторизации, предоставления AI-функционала, поддержки пользователей, защиты от злоупотреблений и проведения платежей.

2. Платежные данные

Платежная обработка осуществляется через YooKassa / ЮMoney. В адрес платежного провайдера передаются только данные, необходимые для приема оплаты и подтверждения транзакций.

3. Хранение

Данные учетной записи и журнал использования хранятся в течение срока обслуживания аккаунта и разумного периода после его прекращения для исполнения обязательств, безопасности и обработки обращений.

4. Запросы субъекта данных

Для запроса на удаление, исправление или выгрузку персональных данных: support@example.com
