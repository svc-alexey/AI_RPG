# Бесплатное продвижение AI RPG Text Game

## Цель продвижения

Бесплатное продвижение должно:

1. привести первых тестеров
2. создать раннее комьюнити
3. показать уникальность проекта
4. собрать фидбек до масштабирования
5. запустить органический рост без рекламного бюджета

## Что именно продвигать

Проект лучше подавать не как "еще одну AI RPG", а через конкретные преимущества:

1. история реально реагирует на действия игрока
2. можно играть короткие и длинные кампании
3. поддерживаются локальные модели через LM Studio
4. можно использовать свой endpoint и свой API key
5. проект сочетает narrative AI и контролируемый state

## Главный принцип бесплатного роста

Лучше всего работает не "официальная реклама", а контент, которым хочется делиться:

1. интересные прохождения
2. смешные фейлы
3. неожиданные развилки
4. красивые старты персонажей
5. сравнения моделей
6. пользовательские истории

## Основные бесплатные каналы

### Telegram

Подходит для русскоязычной аудитории.

Что публиковать:

1. короткие devlog-посты
2. скриншоты сцен и героев
3. лучшие истории игроков
4. голосования за новые сеттинги

### Reddit

Подходит для англоязычной аудитории и сообществ AI / indie / RPG.

Форматы:

1. devlog
2. короткое демо-видео
3. кейс про локальные модели и LM Studio
4. кейс про memory-layer длинной кампании

### YouTube Shorts / TikTok / Reels

Подходят для коротких вирусных фрагментов:

1. один неожиданный момент из кампании
2. контраст между выбором и последствиями
3. сравнение одной сцены на разных моделях

## Простой план первых шагов

1. завести канал/страницу проекта
2. публиковать 2-3 коротких обновления в неделю
3. собирать лучшие игровые истории
4. приглашать первых тестеров в обмен на ранний доступ и влияние на roadmap
