# Монетизация AI RPG

Обновлено под server-first архитектуру (май 2026).

## Принципы

1. Не ломать игровой опыт — монетизация не должна мешать базовому геймплею
2. Не превращать в pay-to-win — продаём удобство и глубину, не победу
3. Покрывать расходы на AI и инфраструктуру
4. Сохранять бесплатный вход для роста комьюнити
5. Учитывать российский рынок: российские платёжные системы, региональные цены

## Уровни доступа

### Уровень 1: Бесплатный

Первый вход, демонстрация ценности, рост комьюнити.

- 1 активная кампания
- Базовые сеттинги (fantasy, detective, sci-fi)
- Короткие кампании (до ~50 ходов)
- Базовая память кампании
- Локальные модели через LM Studio
- Свой API-ключ (OpenAI-совместимый endpoint)
- Карта мира (read-only, базовый слой)

**Расходы на пользователя:** ~$0 (локальные модели) / ~$0.05-0.50 (свой API-ключ, серверная валидация)

### Уровень 2: Premium (299₽/мес)

Основной продукт для вовлечённых игроков.

- До 5 активных кампаний
- Длинные кампании (без ограничения по ходам)
- Расширенная память (глубокая memory-система)
- Полная карта мира (все слои: ландшафт, города, NPC, фракции)
- Фоновые события мира (world simulation)
- Облачные сохранения
- Дополнительные сеттинги по мере добавления
- Приоритетная очередь обработки ходов

**Расходы на пользователя:** ~$1-3/мес (серверная валидация + хранение + AI)

### Уровень 3: Credits (дополнительно)

Для дорогих серверных операций.

- Встроенные облачные AI-модели (не нужно поднимать свои)
- Генерация изображений (персонажи, сцены, карты)
- Long-memory режимы (глубокий контекст через RAG)
- Premium AI-провайдеры (Claude, GPT-4-level)

**Модель:** пакеты credits (например, 100₽ за 100 credits).
Генерация изображения: ~5-10 credits. Ход с облачной моделью: ~1-3 credits.

## Платёжные системы

### Россия
- **Основная:** ЮKassa (бывшая Яндекс.Касса) — карты, ЮMoney, SberPay, СБП
- **Альтернатива:** CloudPayments, Robokassa
- **Крипто:** USDT (для обхода ограничений)

### Международные
- **Stripe** — для зарубежных пользователей
- **Cryptocurrency** — USDT, если Stripe недоступен из РФ

### Важно
- Все платежи проходят через backend (Symmetry)
- Никаких in-app purchases через магазины приложений на старте
- Web-версия — основной путь оплаты

---

## Чего избегать

1. Pay-to-win механик — никогда
2. Агрессивных блокировок базового геймплея
3. Обязательной оплаты для локального LM Studio режима
4. Слишком раннего усложнения монетизации до product-market fit
5. Зависимости от одного платёжного провайдера

## Roadmap монетизации

1. **Pre-PMF (сейчас):** всё бесплатно, сбор фидбека
2. **PMF (10-50 активных пользователей):** вводим Premium, оттачиваем конверсию
3. **Рост (50-500):** добавляем Credits для облачных AI-моделей
4. **Масштабирование (500+):** расширяем сетку, добавляем семейные/групповые планы
