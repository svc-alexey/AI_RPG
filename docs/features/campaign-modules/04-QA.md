# QA: Campaign Modules

- [ ] Ручной сценарий: `detective`-кампания стартует без `Gold/EXP/Level` в UI
- [ ] Ручной сценарий: `fantasy`-кампания стартует с `Inventory` и `Vitality`
- [ ] Ручной сценарий: story prompt активирует `Companions` ещё на этапе создания кампании
- [ ] Ручной сценарий: по narration появляется новый спутник, модуль `Companions` активируется и показывается уведомление
- [ ] Ручной сценарий: предмет добавляется, появляется краткое уведомление, предмет виден в sidebar
- [ ] Ручной сценарий: урон и лечение показывают `delta HP` без блокировки чата
- [ ] Ручной сценарий: на mobile уведомления и sidebar не ломают composer
- [ ] Автоматические проверки: `flutter analyze`
- [ ] Автоматические проверки: релевантные widget/unit tests для module resolver, extraction и UI overlays

## Риски

- Story-driven auto-activation может включить лишний модуль по разовому художественному упоминанию.
- Частые state changes могут превратить уведомления в шум.
- Миграция старых кампаний может включить слишком много модулей "по инерции".
