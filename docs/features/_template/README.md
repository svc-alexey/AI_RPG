# Feature Template

Эта папка используется как шаблон для любой новой фичи.

Стандартный состав:

- `README.md` — краткая сводка фичи
- `01-Architecture.md` — архитектурный анализ и технический план
- `02-PRD.md` — аналитика, требования, сценарии
- `03-Implementation.md` — реализация, чекбоксы, статус
- `04-QA.md` — тесты, риски, приемка
