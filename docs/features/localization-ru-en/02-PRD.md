# PRD: localization-ru-en

## Цель

Пользователь должен иметь два полноценных языковых режима приложения: русский по умолчанию и английский как второй complete mode.

## Сценарии

1. Пользователь запускает приложение и видит русский интерфейс.
2. Пользователь переключает язык на английский и получает английский UI и AI-ответы.
3. Пользователь сохраняет настройку языка между сессиями.

## Требования

1. Вся пользовательская текстовая поверхность должна переключаться между `ru` и `en`.
2. AI-слой должен получать выбранный язык и отвечать в нем.
3. Demo/fallback и системные статусы тоже должны локализоваться.

## Done

1. Язык переключается без ручной правки строк в коде.
2. Приложение стартует на русском.
3. Английский режим полностью доступен.
