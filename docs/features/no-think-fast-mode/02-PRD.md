# PRD: no-think-fast-mode

## Цель

Пользователь локальной модели должен получать более быстрые игровые ответы без поломки JSON-контракта.

## Сценарии

1. Пользователь играет через LM Studio и хочет быстрее тестировать игровые ходы.
2. Пользователь включает fast mode и получает ответ быстрее.
3. Если быстрый режим дает плохой формат, приложение автоматически откатывается на обычный режим.

## Требования

1. Fast mode должен быть доступен для LM Studio.
2. Ответ по-прежнему должен быть совместим с structured parsing.
3. Должен быть fallback на обычный режим.

## Done

1. Fast mode добавлен.
2. JSON-контракт не ломается.
3. Есть безопасный retry без fast mode.
