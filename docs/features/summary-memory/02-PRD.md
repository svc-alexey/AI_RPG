# PRD: summary-memory

## Цель

Пользователь должен иметь устойчивый контекст кампании после паузы, сохранения и длинной игровой сессии.

## Сценарии

1. Пользователь открывает старый save и быстро понимает, что происходит.
2. AI продолжает кампанию без заметной потери ключевого контекста.
3. Sidebar показывает полезную сводку, а не только полный лог сообщений.

## Требования

1. Кампания хранит rolling summary.
2. Кампания хранит активную цель отдельно.
3. Кампания хранит недавние ходы.
4. AI получает structured memory payload.

## Done

1. Memory-слой отделен от старого плоского `summary`.
2. Старые save имеют fallback.
3. UI показывает полезную сводку состояния кампании.
