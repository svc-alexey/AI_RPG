# Приглашение тестеров (RU)

**Использование:** личные сообщения, посты в Telegram, комментарии в тематических чатах.

---

Привет! Я делаю **AI RPG** — narrative RPG с живым серверным миром. Выбираешь сеттинг (фэнтези, детектив, sci-fi), создаёшь героя и играешь текстом. Серверный движок валидирует каждое действие, мир живёт своей жизнью (фоновые события, хроники, карта), а память держит 1000+ ходов.

Сейчас ищу **5–10 первых тестеров**, чтобы получить честный фидбек до публичного релиза. Доступно на Windows, Android и Web. Поддерживает OpenAI-совместимые API и локальные модели через LM Studio.

**Что нужно от тестера:**
- Запустить приложение (Windows / Android / Web)
- Поиграть хотя бы одну короткую сессию (15–30 минут)
- Заполнить короткую форму с отзывом (3–5 минут)
