# Монетизация AI RPG Text Game

## Цель монетизации

Монетизация должна:

1. не ломать игровой опыт
2. не превращать игру в pay-to-win
3. покрывать расходы на AI и инфраструктуру
4. сохранять бесплатный вход для роста комьюнити

Главный принцип: продавать не победу, а удобство, глубину и дополнительные возможности.

## Базовая модель

### Уровень 1. Бесплатный режим

Подходит для первого знакомства.

Что включить:

1. короткие приключения
2. ограниченный набор сеттингов
3. один активный save
4. базовую память кампании
5. локальный LM Studio
6. возможность использовать свой API key

### Уровень 2. Premium / Pro

Основная покупка для вовлеченных игроков.

Что открыть:

1. длинные кампании
2. больше save slots
3. расширенную memory-глубину
4. дополнительные сеттинги
5. более гибкую кастомизацию
6. облачные сохранения, если backend появится

### Уровень 3. Credits / Подписка на дорогие AI-функции

Используется для дорогих серверных операций.

Что сюда можно вынести:

1. встроенные облачные модели
2. генерацию изображений
3. дорогие long-memory режимы
4. premium quality AI-провайдеров

## Рекомендуемая схема

### Бесплатно

1. базовый вход в игру
2. локальные модели
3. короткие кампании

### Premium

1. длинные кампании
2. расширенные save
3. более глубокая memory-система
4. больше narrative/content options

### Credits / subscription add-on

1. дорогой AI
2. дорогой визуальный контент
3. heavy cloud features

## Чего лучше избегать

1. pay-to-win механик
2. агрессивных блокировок базового gameplay
3. обязательной оплаты для локального LM Studio режима
4. слишком раннего усложнения монетизации до product-market fit
